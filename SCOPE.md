# Alcance del laboratorio

Este documento define el alcance autorizado de las pruebas realizadas durante el proyecto académico de seguridad de servidores MCP.

## Dentro del alcance

- Servidor MCP desarrollado por el equipo.
- Procesos ejecutados localmente por el equipo.
- `localhost`.
- `127.0.0.1`.
- Transporte `stdio` cuando sea utilizado.
- Datos ficticios.
- Usuarios y roles ficticios.
- Credenciales y tokens ficticios.
- Herramientas controladas por el equipo.
- Cisco MCP Scanner ejecutado exclusivamente contra nuestro laboratorio.

## Fuera del alcance

- Servidores externos.
- Sistemas universitarios.
- Infraestructura empresarial.
- Sistemas o dispositivos de terceros.
- Sistemas de clientes.
- APIs externas sin autorización.
- Servicios de producción.
- Credenciales reales.
- Tokens reales.
- Datos personales reales.
- Archivos privados reales.
- Infraestructura sin autorización escrita.

## Restricciones éticas

Las pruebas se realizarán exclusivamente en un entorno autorizado y controlado.

No se realizarán pruebas sobre sistemas de producción sin autorización escrita.

No se desarrollarán ni divulgarán exploits o vulnerabilidades zero-day.

Cuando sea necesario demostrar un comportamiento potencialmente peligroso, se utilizará una alternativa inocua y controlada dentro del laboratorio.
